# 👹 リアル鬼ごっこ

スマホのGPSを使って、実際に外を走り回って遊ぶ鬼ごっこWebアプリです。
アプリのインストールは不要で、みんながブラウザで同じURLを開くだけで遊べます。

## あそびかた

1. ホストが「部屋をつくる」を押し、表示された4桁のコードをみんなに伝える（「コードを共有」でURLも送れます）
2. 参加者はコードを入力して参加。ホストはルールを設定して「ゲーム開始」
3. 鬼はランダムに決まります。エリアの中心はホストの現在地です
4. **鬼**には一定間隔ごとに逃走者の位置（❓マーク）が公開されます。近づいたら「確保！」ボタンで一番近い逃走者を捕まえられます
5. **逃走者**は仲間と鬼の位置を見ながら逃げます。鬼にタッチされたら「捕まった…（報告）」でも確保になります
6. 制限時間まで1人でも逃げ切れば逃走者の勝ち、全員確保で鬼の勝ち

### ルール設定

| 項目 | 説明 | 初期値 |
| --- | --- | --- |
| 制限時間 | ゲームの長さ（分） | 15 |
| 鬼の人数 | 開始時の鬼の数 | 1 |
| 確保できる距離 | 鬼と逃走者がこの距離以内なら「確保！」が成功（GPS誤差分の余裕あり） | 15m |
| 位置公開の間隔 | 逃走者の位置が鬼に公開される間隔 | 60秒 |
| エリア半径 | これより外に出ると警告が出ます | 300m |
| モード | 通常（捕まったら牢屋）／増え鬼（捕まったら鬼になる） | 通常 |
| 逃走者に鬼の位置を見せる | OFFにすると緊張感アップ | ON |

## 起動方法

```bash
npm install
npm start          # http://localhost:3000
```

`PORT` 環境変数でポートを変更できます。

### スマホで遊ぶには HTTPS が必要です

ブラウザの位置情報APIは HTTPS（または localhost）でしか動きません。以下のどれかで公開してください。

- **Render / Railway / Fly.io など**にデプロイ（`npm start` で起動。WebSocketが使えるサービスを選んでください）
- 手元のPCで起動して、**Cloudflare Tunnel** や **ngrok** でHTTPS化
  ```bash
  npx cloudflared tunnel --url http://localhost:3000
  ```

### PCで動作確認する（デバッグモード）

`http://localhost:3000/?debug` を複数のタブで開くと、タブごとに別プレイヤーになり、
地図をクリックすると自分の位置を動かせます。GPSなしでゲームの流れを確認できます。

## 構成

```
src/game.js     ゲームロジック（役割決め、確保判定、位置公開、勝敗、見える情報の制御）
src/server.js   Express + Socket.IO サーバー（部屋管理、毎秒のタイマー処理）
public/         スマホ向けフロントエンド（Leaflet + OpenStreetMap の地図）
test/           テスト（npm test）
```

- 位置情報はサーバーのメモリ上にのみ保持され、部屋が空になると破棄されます
- 鬼には逃走者のリアルタイム位置は送られません（公開タイミングのスナップショットのみ）。ズルできないよう、見える情報はサーバー側で絞っています
- 通信が切れても同じ端末で開き直せば自動で部屋に戻れます

## 安全のために

- 道路への飛び出し、私有地・立入禁止区域への侵入はしないでください
- 画面を見ながら走らないでください
- 公園など、安全で広い場所で遊びましょう
